I'm a Computer Science student building toward a career as a MERN Stack Developer. My work centers on the JavaScript ecosystem — React on the frontend, Node.js and Express on the backend, MongoDB for data — and I enjoy the process of taking an idea from a rough plan to a working, deployed application.

Most of what I know comes from building: personal projects, coursework, and a fair amount of trial and error along the way.
